{# Features Section #}

Dead Simple API

Builder pattern, closure-based children, zero boilerplate. If you can write Rust, you can build UIs.

Cross-Platform

One codebase → web, desktop, Android, iOS. No platform-specific code required.

Shaders & Effects

Per-element and group shaders, visual rotation, built-in effects. GPU-powered beauty.

Accessibility

AccessKit integration, keyboard navigation, screen reader support. Built in, not bolted on.

Debug View

Browser DevTools-style inspector built right into the engine. No other Rust UI library has this.

Text Input

Full text editing: cursor, selection, undo/redo, multiline, styled text, virtual keyboard.
